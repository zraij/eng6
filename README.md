# English 6 · المدرّس

الكتاب التفاعلي للغة الإنكليزية للصف السادس الإعدادي (منهج English for Iraq): الوحدات الثماني كاملة (كتاب الطالب وكتاب النشاط)، الأدب (Pride and Prejudice و As You Like It)، الإنشاءات المطلوبة وزارياً، مرجع القواعد، صانع الأسئلة، التحضير اليومي، ووضع العرض على الشاشة التفاعلية، وكتاب ناطق.

- **الموقع:** https://zraij.github.io/eng6/ (يحتاج تسجيل دخول)
- **إدارة الحسابات:** https://zraij.github.io/eng6/admin.html (لصاحب الموقع فقط)
- **لوحة إدارة موحّدة:** نفس `admin.html` موجود بكل الكتب ويدير كل الكتب من مكان واحد (أزرار للتبديل بين الكتب). أي تعديل عليه لازم ينسخ لكل المستودعات.
- **الاشتراكات:** كل حساب (عدا المدير) له تاريخ انتهاء `e` بـ `users.json` (`pm` = عدد الأشهر، `tr` = أيام التجربة). الحسابات القديمة بدون تاريخ تنتهي `2026-12-01` (من 1 تشرين الثاني لمدة شهر). عند الانتهاء تظهر شاشة التجديد برقم 07746451098.
- **تنبيه للمطوّر:** كود الاشتراك (`subFetch` / `subExpired` / `subBadge`) مضاف بالجزء غير المشفّر من `index.html`؛ بعد أي إعادة بناء تأكد أنه موجود.
- **رابط التثبيت (يُرسل للأساتذة):** https://zraij.github.io/eng6/install.html

محتوى البرنامج مشفّر، ولا يُفتح إلا بحساب صحيح. الحسابات محفوظة في `users.json` بشكل مشفّر، وتُدار من صفحة الإدارة. كل حساب أستاذ يُقفل على أول جهاز يدخل منه، وحساب المدير مستثنى من القفل. حساب الشاشة التفاعلية يُضاف من صفحة الإدارة.

صور صفحات الكتاب (`pages/`) والصور المقتطعة (`img/`) ملفات عامة غير مشفّرة.
